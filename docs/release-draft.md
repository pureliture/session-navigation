# Draft release blurb

Session Navigation gives OMP, Hermes and Paseo reversible context controls: rule-based Hide with key-line retention, session-model Summarize, and Unhide recovery, while preserving originals and changing only outgoing request copies. In our captured evaluations, tool results occupied roughly 70–81% of prompt tokens; v4 reduced final-request tool-result tokens by 53–66% with no measured task-quality loss, and synthetic focus replay used about 97–98% fewer prompt tokens with no statistically significant accuracy difference. These small evaluations do not demonstrate improved accuracy or guaranteed cost savings: hidden-only details require recovery (0/30 without it), edits break prompt-cache prefixes, and batching can mitigate that overhead. See the [evaluation summary](../README.md#evaluation) for results and limitations.
